# Birthday FM audio slots

Replace these `.mp3` files with your real recordings or songs, keeping the filenames unchanged:

- `page-01-intro-01.mp3` — optional opening station ident
- `page-03-track-01.mp3` through `page-03-track-06.mp3` — playlist tracks 1–6
- `page-05-final-broadcast-01.mp3` — final voice note

The page number is the screen where the audio appears; the final number is the sequence on that screen.
